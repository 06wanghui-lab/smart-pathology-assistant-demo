# UNI Model Attribution

The prediction results displayed in this static demonstration were generated by a project classifier built using features extracted with UNI, a pathology foundation model developed by Mahmood Lab AI for Pathology at Harvard Medical School and Brigham and Women's Hospital.

- Model page: [MahmoodLab/UNI](https://huggingface.co/MahmoodLab/UNI)
- Repository: [mahmoodlab/UNI](https://github.com/mahmoodlab/UNI)

This repository contains only pre-generated prediction outputs. It does not include, publish or redistribute UNI model weights or checkpoints.
